# Backend · Magmafy OS (Google Apps Script)

الملفات دي هي الـ backend بتاع الـ CRM: الشيت هو قاعدة البيانات، والـ Apps Script هو الـ API اللي الموقع بيكلمه.

| الملف | فيه إيه |
|---|---|
| `Code.gs` | شكل الشيت (التبويبات والأعمدة)، الحجز من الموقع العام، المواعيد المتاحة، الإيميلات، الملخص اليومي، تتبع تعديلات الشيت |
| `Crm.gs` | الدخول بالكود، العملاء، المهام، الاجتماعات، الداشبورد |
| `Api.gs` | **جديد:** بوابة موقع الـ CRM (`action: 'crm'`)، الإعلانات، المحادثات، الإشعارات، طلبات الانضمام، سجل التعديلات، الإعدادات، الفريق، القوالب |
| `test/` | اختبارات بتشغّل الملفات دي على شيت وهمي وتتأكد إن كل رد مطابق للي الموقع مستنيه (`npm test`) |

## التركيب (مرة واحدة)

1. افتح الشيت ← **Extensions ← Apps Script**.
2. استبدل محتوى `Code.gs` و `Crm.gs` بالنسخ اللي هنا، واعمل ملف جديد اسمه `Api.gs` وحط فيه محتوى `Api.gs`. سيب ملف `crm.html` زي ما هو.
3. احفظ (Ctrl+S)، وارجع للشيت واعمل Refresh.
4. من قايمة **Magmafy** شغّل **① تجهيز الشيت**. هيضيف 7 تبويبات جديدة من غير ما يلمس البيانات الموجودة: الإعلانات، المحادثات، الرسائل، الإشعارات، القراءات، طلبات الانضمام، سجل التعديلات. ولو أول مرة، شغّل كمان **② تفعيل الأتمتة**.
5. في Apps Script: **Deploy ← Manage deployments ← ✏️ Edit ← Version: New version ← Deploy**.
   - Execute as: **Me**
   - Who has access: **Anyone**
   - تعديل الـ deployment الموجود بيخلّي الرابط زي ما هو، والموقع العام (الحجز) هيفضل شغال.
6. انسخ رابط الـ Web app (آخره `/exec`).
7. في GitHub: **Settings ← Secrets and variables ← Actions ← Variables ← New repository variable**
   - Name: `VITE_API_URL`
   - Value: رابط `/exec`
8. روح **Actions** ← آخر run ← **Re-run all jobs**. بعد دقيقة الموقع هيشتغل على البيانات الحقيقية.
9. اتأكد إن كل واحد في الفريق موجود في تبويب «الفريق» وقدامه «نشط = نعم». والأدمن دوره «أدمن».

## الإعدادات الجديدة (تبويب «الإعدادات»)

| الإعداد | القيمة الافتراضية | الشرح |
|---|---|---|
| `CRM_URL` | `https://mrvoroo.github.io/Magmafy-CRM/` | بيتحط في إيميلات الإعلانات، وقبول طلبات الانضمام، والملخص اليومي |
| `CHAT_POLL_SECONDS` | `10` | كل كام ثانية المحادثة المفتوحة بتتحدث |

## إزاي الموقع بيكلم الـ Script

```
POST <رابط /exec>     Content-Type: text/plain
{ "action": "crm", "fn": "crmBootstrap", "args": [], "token": "<الجلسة>" }

← { "ok": true, "data": … }
← { "ok": false, "code": "SESSION_EXPIRED | FORBIDDEN | UNKNOWN_FUNCTION | APP_ERROR | SERVER", "error": "…" }
```

- `APP_ERROR`: رسالة بالعربي بتظهر للمستخدم زي ما هي ("اكتب العنوان والنص").
- `SERVER`: مشكلة غير متوقعة، وبتتسجل في تبويب «سجل الأخطاء».

## ملاحظات

- **سجل التعديلات** بيسجل كل تعديل: من الموقع (المصدر = CRM)، ومن الشيت باليد (المصدر = الشيت)، ومن حجوزات الموقع العام.
- **الإشعارات** بتتعمل لما: حد يحجز من الموقع، عميل أو مهمة تتسند لحد، إعلان يتنشر أو يتعمله تذكير، رسالة أو منشن، أو طلب انضمام جديد.
- لو حد اتشال من «الفريق» أو اتحط قدامه «نشط = لا»، بيخرج من الموقع أول ما يعمل أي حاجة.
- حصة الإيميلات في Gmail العادي حوالي 100 إيميل في اليوم. نسخة الإعلان بالإيميل بتتبعت كإيميل واحد لكل الناس (BCC).
